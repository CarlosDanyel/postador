Postador

Uma ferramenta pessoal para publicar vídeos nos meus próprios canais.

O Postador roda só no computador do dono. Ele envia os vídeos que o próprio dono produziu para os canais e as páginas dele, com o título, a descrição e a capa de cada vídeo. Ele não é um serviço aberto ao público: ninguém se cadastra e nenhuma outra pessoa usa o app.

O que ele faz

  • YouTube: envia o vídeo, o título, a descrição, as tags e a thumb para o canal do dono pela YouTube Data API (YouTube API Services) e confere se o vídeo terminou de processar.
  • TikTok: envia o vídeo para a conta do dono pela Content Posting API.
  • Facebook: publica Reels na Página do dono pela Graph API.
