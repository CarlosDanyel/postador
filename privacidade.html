Política de Privacidade

Postador · em vigor desde 22/10/2026

O Postador é uma ferramenta pessoal. Ela roda só no computador do dono e é usada só por ele, para publicar os próprios vídeos nos próprios canais. Esta página explica que dados o app acessa, onde eles ficam e como revogar o acesso.

Dados que o app acessa

  • YouTube (Google): com as permissões youtube.upload e youtube.readonly, o app envia vídeos, títulos, descrições e thumbs ao canal autorizado e lê o nome do canal e o estado de processamento dos vídeos que ele mesmo enviou.
  • TikTok: as informações básicas do perfil e a permissão de enviar vídeos.
  • Facebook: a lista de Páginas que o dono administra e a permissão de publicar nelas.

O app não lê comentários, mensagens, contatos, inscritos nem dados de outras pessoas.

Onde os dados ficam

Os tokens de acesso ficam só num arquivo de configuração no computador do dono. Não existe servidor do Postador, banco de dados, análise de uso ou cookies. Os vídeos e os textos vão direto do computador do dono para a plataforma escolhida, e o app guarda localmente só um registro do que foi publicado (o link e a data).

Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros. Os dados só são enviados às próprias plataformas (YouTube, TikTok e Facebook), para fazer a publicação pedida pelo dono.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

YouTube API Services

O Postador usa os YouTube API Services. Os dados tratados pelo Google seguem a Política de Privacidade do Google, e o uso do YouTube segue os Termos de Serviço do YouTube.

Como revogar o acesso

  • Google/YouTube: em myaccount.google.com/permissions, remova o acesso do "Postador".
  • TikTok: em Configurações e privacidade → Segurança → Apps e serviços.
  • Facebook: em Configurações → Integrações comerciais.

Ao revogar, o token guardado no computador deixa de funcionar. Apagar o arquivo de configuração remove todos os dados guardados pelo app.
